## 2. Linux에서 쉘 스크립트 작성하기

이제 리눅스에 진입을 했으니 본격적으로 간단한 스크립트를 하나 작성해보겠습니다.
```
nano my_first_script.sh
```
> **touch**는 생성, **nano**는 접속을 말합니다.

![alt text](/assets/img/imagenano1.png)

해당 스크립트를 입력하면 위와같은 화면이 나오게됩니다.

이어서 화면에 이런 짧은 스크립트를 추가로 입력해보겠습니다.


### 2-1 Linux 환경에 진입
```bash
#!/bin/bash
DB_NAME="jongsun-db"

echo "--------------------------------------"
echo "데이터 엔지니어 ENZO님의 DB 상태를 점검합니다..."

# 도커 컨테이너 상태 확인
STATUS=$(docker ps -f "name=$DB_NAME" --format "{{.Status}}")

if [ -z "$STATUS" ]; then
    echo "경고: $DB_NAME 컨테이너가 꺼져 있거나 존재하지 않습니다!"
else
    echo "정상: $DB_NAME 가 현재 '$STATUS' 상태입니다."
fi
echo "--------------------------------------"
```

![alt text](/assets/img/imagenano.png)

위 스크립트를 복사 한 후 터미널에서 오른쪽 마우스를 클리하게 되면 이미지처럼 그대로 복사가 되게됩니다.


### 2-2 NaNo 편집기에서 빠져나오는 단축키

nano 편집기에서 빠져나오는 단축키를 순서대로 누르세요.


> 1. Ctrl + O (저장하기 명령)

> 2. Enter (파일명 check_db.sh 확인)

> 3. Ctrl + X (편집기 종료)  

그 다음 Y를 누르고 엔터를 한번더 눌러주면 저장 + 나오기가 성공하게 됩니다!

### 2-3 쉘 스크립트 자동화

```bash
jsjs@JSJS:/mnt/c/Users/urina$ chmod +x check_db.sh
```
먼저 `chmod +x check_db.sh` 는 **실행권을 주겠다** 라는 의미이고,
```bash
chmod: changing permissions of 'check_db.sh': Operation not permitted
```

`not permitted`는 **제 windows OS의 경로(/mnt/c/Users/urina) 때문입니다.**
현재 저는 부트캠프에서 대여한 레노버 Window를 사용중이기 때문에, 
`chmod`는 파일에 '너는 실행 파일이야!!'라고 문패를 다는 명령어인데, 윈도우 땅에서는 리눅스의 문패 다는 방식이 통하지 않습니다.
**그래서 리눅스가 "권한을 바꾸고 싶은데 내 마음대로 안 돼!"라고 에러를 낸 상황입니다.**


```bash
jsjs@JSJS:/mnt/c/Users/urina$ ./check_db.sh

--------------------------------------
데이터 엔지니어 ENZO님의 DB 상태를 점검합니다...

정상: db 가 현재 'Up 51 minutes' 상태입니다.
--------------------------------------
jsjs@JSJS:/mnt/c/Users/urina$
```

**여기가 바로 `./check_db.sh` 쉘 스크립트를 자동화하는 구간입니다.**
