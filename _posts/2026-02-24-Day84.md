### 1. 데이터 엔지니어링 

어제 전체적인 기획 설계가 끝났습니다

![alt text](/assets/img/image205.png)

거진 2주 이상을 주제때문에 갈팡질팡하다 최종적으로 팝업스토어로 굳어졌고 
이젠 최대한 긍정적인 방향으로 프로젝트를 이끌어가야 팀원들도 믿고 본인의 업무에 집중할 수 있을거라 생각했습니다.

그리고 최종적으로 H&M의 테이블을 결측치와 이상치 + 피처 엔지니어링 + 메모리/용량 축소까지 시키며 깔끔한 전처리 통합 테이블을 배포했습니다.

```Python
from sklearn.preprocessing import LabelEncoder
import gc # 가비지 컬렉터 (메모리 청소)
data_path = '../Data Folder/H&M dataset' # CSV 파일들이 있는 폴더 경로
```

```python
# Transactions 테이블 
df_trans = pd.read_csv(
    os.path.join(data_path, 'transactions_train.csv'),
    dtype={
        'article_id': str, # 0으로 되어있는 데이터 문자열 고정
        'sales_channel_id': np.int8 # 1,2밖에 없기 때문에 int8
    }
)
```
- `article_id`: 0으로 되어있는 데이터를 문자열로 고정했습니다.
- `sales_channel_id` : 1과 2밖에 없었기 때문에 **int8**로 용량을 축소시켰습니다.


```python
# 날짜형 변환
df_trans['t_dat'] = pd.to_datetime(df_trans['t_dat'])
```
- `t_dat` 컬럼이 날짜형이 아니였기에 날짜형으로 변환하였습니다. 

```python
# 가격 float32로 축소시킴
df_trans['price'] = df_trans['price'].astype(np.float32)
# 가격 X 590 -> 스웨덴 크로나 --> 원 환산 
df_trans['price'] = df_trans['price'] * 590
```
- `price`컬럼을 실수형32비트로 축소시켰습니다
- 또한 스웨덴 크로나 단위를 원화로 환산시켰습니다.

```python
# Customer_ID 문자열에서 정수형인코딩으로 축소시킵니다.
le_customer = LabelEncoder()
df_trans['customer_id'] = le_customer.fit_transform(df_trans['customer_id'])
df_trans['customer_id'] = df_trans['customer_id'].astype(np.int32) # int 32로 변환합니다.
``` 
- `customer_id` 컬럼을 정수형 인코딩으로 축소시켰습니다.
- 또한 int32비트 타입으로 변환하여 용량과 메모리를 최적화했습니다.

```python
# 나중에 원래 ID가 필요할 때를 대비해 매핑 테이블 저장
customer_mapping = pd.DataFrame({
    'original_id': le_customer.classes_,
    'encoded_id': np.arange(len(le_customer.classes_))
})
customer_mapping.to_parquet('customer_mapping.parquet', index=False)
```
- 혹시라도 나중에 ID가 필요할 때를 대비해서 매핑 테이블로 저장하였습니다.
- 그리고 해당 매핑 테이블을 저장하였습니다.

```python
# Article_ID도 정수형으로 변환
df_trans['article_id'] = df_trans['article_id'].astype(np.int32)
``` 
- `article_id` 컬럼을 마찬 정수형 32비트로 변환하였습니다.

```python
# 메모리 확인용
reduced_mem = df_trans.memory_usage(deep=True).sum() / 1024**2
print(f"현재 메모리: {reduced_mem:.2f} MB")

# parquet 변환 --> 용량 확인해야함.
df_trans.to_parquet('transactions.parquet', index=False)
print(f'파일 생성 확인')

# 메모리 청소
del df_trans
gc.collect()
```


여기까지가 1차적인 테이블 통합 전처리 및 메모리/용량 최적화입니다.
