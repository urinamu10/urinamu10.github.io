### 2. 자료구조의 메모리 효율 (Data Structure)
Python의 편의성에 속지 마십시오. 엔지니어는 메모리를 관리해야 합니다.

학습 키워드: Array vs Linked List, Hash Table의 원리, 시간 복잡도(Big O notation).

미션: Python의 List와 Set에서 특정 값을 찾을 때, 왜 Set이 압도적으로 빠른지 메모리 주소 체계 관점에서 이해하십시오.

### 3. 리눅스 커널과 프로세스 (The OS)
리눅스는 엔지니어의 공기입니다.

학습 키워드: Kernel vs Shell, Process vs Thread, File System Hierarchy (FHS).

미션: "리눅스에서는 모든 것이 파일이다(Everything is a file)"라는 문장의 의미를 파악하십시오.
