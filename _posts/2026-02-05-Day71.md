#### 125. List the Products Ordered in a Period

[Leetcode-List the Products Ordered in a Period](https://leetcode.com/problems/list-the-products-ordered-in-a-period/description/)


- **테이블** 

![alt text](/assets/img/image115.png)
![alt text](/assets/img/image116.png)

- **문제**

> 2020년 2월에 최소 한 대가 주문된 제품명과 100개 이상의 수량을 얻는 솔루션을 작성하세요.
> 결과 표를 어떤 순서로든 반환하세요.
{: .prompt-info }


- **풀이** 

> (1) 고객ID별 2020-02에 주문된 총합이 100개 이상의 제품의 이름

두 테이블을 `Join`하여 2020-02에 고객 ID를 기준으로 총합이 100개가 넘어가는 제품을 필터링합니다.

```sql
select p.product_name,
       sum(o.unit) as unit
from products p
join orders o
    on o.product_id = o.product_id
where date_format(o.order_date, '%Y-%m') = '2020-02'
group by o.product_id
having unit >= 100 ;
```


#### 126. Find Users With Valid E-Mails
[Find Users With Valid E-Mails](https://leetcode.com/problems/find-users-with-valid-e-mails/description/)

- **테이블** 

![alt text](/assets/img/image130.png)


- **문제**

>1. 유효한 이메일을 가진 사용자를 찾는 솔루션을 작성하세요.
>2. 유효한 이메일은 접두사 이름과 도메인을 가집니다.
>3. 접두사 이름은 문자(대문자 또는 소문자), 숫자, 밑줄, 마침표 및/또는 대시를 포함할 수 있는 문자열입니다. 접두사 이름은 반드시 글자로 시작해야 합니다.`'_''.''-'`
>4. 도메인은 입니다.'@leetcode.com'
결과 표를 어떤 순서로든 반환하세요.
{: .prompt-info }


- **풀이**

> (1) 특정 이메일을 찾기

조건)1 접두사 이름은 문자, 숫자, 밑줄, 마침표 및/또는 대시를 포함할 수 있는 문자열, 반드시 _ . - 로 시작해야함
조건)2 @leetcode.com 도메인로 반드시 끝나야합니다.

```sql
SELECT 
    user_id, name, mail
FROM 
    Users
WHERE 
    mail REGEXP '^[a-zA-Z][a-zA-Z0-9._-]*@leetcode\\.com$';
```
