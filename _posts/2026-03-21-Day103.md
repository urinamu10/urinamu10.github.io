## 1. Revising the Select Query II

>테이블 정보
{: .prompt-info }

![alt text](/assets/img/imageSQL1.png)

>문제
{: .prompt-tip }

```plain text
1. NAME (도시 이름) 필드만 출력하세요.

2. CountryCode가 **'USA'**인 미국 도시여야 합니다.

3. POPULATION이 120,000보다 커야 합니다.
```

>풀이
{: .prompt-note }

**`Countrycode`가 `USA`이면서 `Population`이 120,000보다 큰 미국의 도시 `NAME`을 추출합니다.**

```sql
SELECT NAME
from CITY
where countrycode = 'USA'
and (population >= 120000)
```

## 2. Select All

>문제
{: .prompt-tip }

```plain text
1. CITY 테이블의 모든 행을 쿼리하세요
```

>풀이
{: .prompt-note }

**CITY 테이블에서 모든 행과 컬럼을 쿼리합니다.**

```sql
SELECT *
from CITY
```

## 3. Select By ID

>문제
{: .prompt-tip }

```plain text
1. CITY 테이블에서 ID가 1661인 모든 행렬을 쿼리하시오 
```

>풀이
{:.prompt-note }

```sql

from CITY
where ID = 1661
```

## 4. Japanese Cities' Attributes
https://www.hackerrank.com/challenges/japanese-cities-attributes/problem?isFullScreen=true

>문제
{: .prompt-tip }

```plain text
1. 일본의 모든 도시를 쿼리하시오.
2. 일본의 countryCode는 `JPN`입니다.
```



>풀이
{:.prompt-note }

**Where 조건절에 countrycode를 JPN으로 설정한 후 모든 행렬을 쿼리합니다.**

```sql
SELECT *
FROM CITY 
where countrycode = 'JPN'
```
