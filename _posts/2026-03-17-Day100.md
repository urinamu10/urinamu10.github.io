### 1. Docker는 뭘까?

![alt text](/assets/img/imagedocker1.png)

오늘부터 새롭게 배우려는 `Docker`에 대해서 알아보려고합니다.

엔지니어링의 기초중에 기초이자 **소프트웨어용 표준 컨테이너 박스**인 `docker`를 예시를 들어 설명해보면, 
우리가 예전에 배에 물건을 실을 떄 각기다른 제품군들을 싣기엔 힘들고 망가지기도 쉬웠습니다.
하지만 규격화된 컨테이너가 등장하면서 안에 무엇이 들었든 크레인으로 툭툭 실어 나를 수 있게되었죠.

여기서 사용하는 `docker`도 동일한 역할을 하게됩니다.

코드, 라이브러리, 설정 파일 통째로 **docker 컨테이너**에 옮기면 어디에서 누구던지 윈도우던 맥이던 리눅스던 똑같이 실행시킬수가 있는 도구입니다.

서로다른 환경에서 다른 버전으로 충돌할 일도 없어지고 
심지어는 아예 특정 프로그램을 다운받지 않아도 터미널상에서 docker를 통해 빠르게 띄울 수 가 있죠.

#### 1-3 docker에 접속

```terminal
docker run --name 서버이름-db -e POSTGRES_PASSWORD=비밀번호 -p 5432:5432 -d postgres:16
```
해당 스크립트를 하나씩 설명해보겠습니다.

> `--name 이름-db`

컨테이너의 이름을 직접 설정하는 코드로 이름이라고 되어있는곳에 원하는 컨테이너명을 넣어주시면됩니다.

> `-e POSTGRES_PASSWORD=비밀번호`

DB 접속 PASSWORD를 설정하는 곳으로 비밀번호에 설정하고싶은 비밀번호를 적어주시면 됩니다.

> `-p 5432:5432 `

내 컴퓨터의 5432 포트와 도커의 5432 포트를 연결합니다
이는 DB 전용 통로입니다

> `-d postgres:16`

postgres 16버전 이미지를 가져와서 백그라운드(-d)에서 실행합니다.

### 2. docker에서 postgreSQL 접속하기

```terminal 
docker exec -it 이름-db psql -U postgres
```
본격적으로 postgresSQL에 접속해보겠습니다.

**이름** 칸엔 위에서 설정한 내 컨테이너명을 삽입해주세요.

![alt text](/assets/img/imagePOST.png)

위 이미지처럼 좌측에 `plostgres=#`이 나온다면 터미널과 **docker**만으로 **postgreSQL**에 접속을 성공한 것입니다.
